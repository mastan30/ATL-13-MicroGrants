Notebook Data Layer Summary & Diagram

Summary of Tables

The notebook creates a total of six tables in BigQuery. The data splits into Node tables (things), Edge tables (relationships), and Attribute tables (enrichment data). This explicit division matches exactly what BigQuery's CREATE PROPERTY GRAPH statement requires.

Table Name Role How Real? Description
businesses Node Real Registered businesses in the corridor. Source: San Francisco city open data.
employer_blocks Node Real jobs, Approx. Location Workplace census blocks with real LEHD job counts. Locations are approximated to the census tract level.
supplies Edge Modeled Pairing Represents supply-chain relationships. BEA industry purchase intensity allocated probabilistically to co-located business pairs.
draws_footfall_from Edge Modeled Pairing Represents consumer foot traffic. LEHD workplace job counts allocated to nearby consumer businesses.
borrowed_from Edge Fully Real SBA 7(a) FOIA loan records (FY2020-present) showing business to lender relationships, including failures (charge-offs).
tract_demographics Attribute Real ACS (American Community Survey) 5-year estimates for census tracts overlapping the corridor.
